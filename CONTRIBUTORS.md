# Contributors

The GitHub contributor API was checked on 16 November 2026. Its currently attributed contributor is [CarinaSchoppe](https://github.com/CarinaSchoppe). Git author-name variants identify the same person and are not listed as extra team members.

The [live contributor graph](https://github.com/Luminovia-Training-Consulting/Luminovia-Management-Tool/graphs/contributors) is the current record as contributions change. Contribution counts are deliberately not copied into this dated snapshot. Attribution grants no repository permission or review exception.

To contribute, read [CONTRIBUTING](CONTRIBUTING.md), the [agent guide](AGENTS.md) where applicable, and the full [implementation plan](docs/IMPLEMENTATION_PLAN.md). Useful contributions include reproducible bug reports, focused fixes, permission-boundary tests, integration/browser acceptance and accurate documentation. Preserve authored content, licences and the complete product scope.
