# PDF assets and dependency provenance

`DejaVuSans.ttf` is copied without modification from the local official Arch package `ttf-dejavu 2.37+18+g9b5d1b2f-8`, path `/usr/share/fonts/TTF/DejaVuSans.ttf`. SHA-256: `6038a160b491e121c1f12c7bccb4a9c8730296e3adc1086a059404ed84b7451c`. The complete installed font license is retained as `LICENSE-DejaVu.txt`. Upstream: https://github.com/dejavu-fonts/dejavu-fonts . The runtime embeds only the glyph subset used in each PDF. Unsupported characters fail with `unsupported_glyph`; names are never
silently transliterated or replaced.

The local `vendor/pdf-runtime.js` is generated from `vendor-source.ts`, exactly `pdf-lib 1.17.1` and `@pdf-lib/fontkit 1.1.1`. `deno.lock` retains exact transitive package versions and registry integrity hashes. The runtime imports the local bundle so an immutable deployment does not resolve newer transitive npm versions. `vendor/pdf-runtime.d.ts` preserves upstream types. License notices for the actual six runtime packages are in `vendor/licenses/`; the published fontkit package provides its
MIT declaration in package metadata/README, which is recorded with its named authors.

Reproduction with the repository's pinned Deno 2.9.6:

```bash
node node_modules/deno/bin.cjs bundle --no-config --node-modules-dir=none --lock=supabase/functions/course-documents/deno.lock --frozen-lockfile --platform=browser --minify --declaration --output=supabase/functions/course-documents/vendor/pdf-runtime.js supabase/functions/course-documents/vendor-source.ts
```

Prepend the generated vendor file's existing `deno-lint-ignore-file` provenance line after reproduction; application source remains linted. The bundler's pinned internal esbuild 0.25.5 is a build tool, not an Edge import. An isolated `npm install --package-lock-only --ignore-scripts` and `npm audit --audit-level=low` of these exact direct dependencies reported **zero vulnerabilities** on 16 November 2026; this is a point-in-time package advisory check, not a general security certification.

The entire reviewed function directory, including font, license, local runtime and lock, is included by the existing immutable release packager's recursive `supabase/functions` collection and mounted read-only. Private document facts and generated bytes are never cached in these assets. Font bytes are public static data held in memory; the only runtime filesystem read is the embedded font. Runtime behavior is exercised by `deploy/hostinger/selfhost/course-documents.test.mjs` using the exact
configured Edge Runtime digest, read-only source and a writable temporary cache, with networking disabled.
